# Actual Unicode renderer previews

Generated by `cargo +stable run --example git_graph_preview -- target/git-graph-preview`.
Graph geometry and colours come from `git_render`; labels and selection are illustrative fixture presentation, not a live Navigator screenshot.

Each retained case has SVG, PNG, ANSI and plain-text forms. PNGs use `rsvg-convert`; terminal font appearance still needs integration review. The bridge is `⌢` (independent crossing paths), arrows indicate horizontal ancestry, and `┊` means older history is not loaded.
